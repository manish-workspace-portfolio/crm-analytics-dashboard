# CRM Analytics Dashboard | Leads & Opportunities Analysis

## Project Overview

This project analyzes CRM leads and sales opportunities to evaluate lead conversion, opportunity pipeline performance, expected revenue, and sales trends.

The project uses MS Excel, MySQL for data preparation and analysis, Power BI for interactive dashboard reporting, and Tableau Public for data visualization.

## Business Objectives

- Analyze lead volume and lead conversion performance.
- Evaluate leads by status, source, industry.
- Monitor active, won, and lost sales opportunities.
- Analyze expected revenue by opportunity type and industry.
- Compare expected revenue with total pipeline/forecast revenue over time.
- Identify trends that support data-driven sales decisions.

## Tools & Technologies

- Microsoft Excel – Initial data analysis and preparation
- MySQL – Data cleaning, transformation, SQL queries, and views
- Power BI – Interactive dashboards and KPI reporting
- Tableau Public – Data visualization and dashboard development

### 2. Opportunity Pipeline Analysis

### 3. Expected Revenue & Total Pipeline Revenue Analysis

note - Forecast revenue is calculated using opportunity amount multiplied by its probability percentage.
